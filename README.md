### Solar Sensing

**Geospatial Analysis · Satellite Imagery · Computer Vision**

An academic project studying rooftop solar adoption in Hayatabad, Peshawar, using multi-year satellite imagery.

Project work includes:

- Collection and preparation of satellite imagery covering 2021–2025.
- Construction of a dataset containing 1,275 image patches.
- Preliminary annotation using Hugging Face and label review/correction using Roboflow.
- Investigation of computer-vision approaches, including CNN-based methods, Mask R-CNN and U-Net.
- Development of a temporal-analysis workstream.

Temporal modelling remains under development. Forecasting performance and model results will only be reported when supported by completed experiments and evaluation.

*A dedicated research repository and reproducibility documentation are in preparation.*
